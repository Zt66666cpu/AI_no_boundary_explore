# 答辩提纲

> 答辩占总分 40%，时间与形式待官方通知。以下按 5 分钟与 10 分钟两版准备。

## 1. 五分钟版

| 时间 | 内容 |
|---|---|
| 0:00–0:30 | 问题：空背包到铁镐，3600 秒 / 5M tokens |
| 0:30–1:30 | 方案：一句话路线 + 架构图 |
| 1:30–3:00 | 实现：状态机、动作层、LLM 层、失败恢复 |
| 3:00–4:00 | 结果：平均分、三阶段检查点、对照实验 |
| 4:00–4:30 | 失败与改进：一个具体案例 |
| 4:30–5:00 | 局限与下一步 |

## 2. 十分钟版

在五分钟版基础上增加：

- 计分公式与策略取舍（为什么先保铁链、火把何时做）
- 两组对照实验的细节（种子、步数、tokens）
- 一次完整失败复盘

## 3. 幻灯片结构（8–10 页）

1. 标题与分工
2. 任务与约束
3. 总体架构
4. 状态机
5. 动作层与合成
6. LLM 调用与提示词
7. 结果总表
8. 对照实验
9. 失败案例
10. 局限与下一步

## 4. 必问题库

方案设计：

- 为什么选规则 + LLM，而不是纯 LLM 或纯规则？
- 状态机有哪些状态，转移条件是什么？
- 为什么这样安排木、石、铁的顺序？

工程实现：

- 8 维动作怎么封装，合成索引怎么维护？
- 怎么确认动作真的生效？
- 模型返回非法 JSON 怎么办？
- 3600 秒和 5M tokens 怎么控制？

实验分析：

- 对照组差多少，差在哪？
- 换一个隐藏种子还成立吗？
- 最典型的失败是什么，改了什么？

合规：

- 有没有联网？有没有读写环境内部数据？
- 有没有人工介入？
- 第三方代码和模型怎么声明？

## 5. 演示预案

- 主方案：现场跑一段录屏，不依赖网络
- 备方案：静态截图 + `review.html`
- 再备：本地保存的 `replay.mp4`
- 演示前检查：分辨率、声音、字幕、播放器

## 6. 彩排

- 至少完整彩排 2 次，计时
- 每次彩排记录超时点与卡壳问题
- 答辩前一周确定主答与补充人
