## A. 代码 ZIP

- [ ] 根目录直接是 `agent.py` 与 `config.json`，没有多套一层文件夹
- [ ] 文件数 ≤ 256，解压后 ≤ 64 MB
- [ ] `config.json` 只有 `model` 与 `agent` 两个顶层键
- [ ] `model.api_key` 为空，没有真实密钥
- [ ] 用官方 `pack_agent.py` 打包，包含 `technical-route.md` 与依赖模块
  - 打包命令：`python pack_agent.py --policy model`，正式策略选 `model`；`--policy` 选错会打出只会前进的 baseline
- [ ] 干净目录解压后能按说明运行
- [ ] 记录 ZIP 的 SHA-256 与打包时间
