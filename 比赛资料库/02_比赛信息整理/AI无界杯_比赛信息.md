## 五、三条赛道

### 赛道 A · 观行知意（人体日常行为识别）

- 关键词：CV · 模型架构 · 时序建模；技术栈 Python / PyTorch
- 任务：输入**深度视频**，判断人在做什么。用 **CUHK-X** 数据集的深度图像识别洗脸、喝水、扫地等 **40 类日常动作**
- 要做：数据处理 → 分类模型训练 → 预测；可在验证集自检；兼顾准确率与推理效率
- 资源：每队 **100 元 AutoDL 算力券**；组织方提供训练/验证数据、开发材料与统一测评
- 测评指标：动作识别准确率、各类别识别表现、推理效率
- 交付：训练与推理代码、模型权重、公开验证集预测结果、技术报告与运行说明

### 赛道 B · 无界探索（开放世界智能体）★ 我们参赛的赛道

- 关键词：Agent · 任务规划 · 工具调用；技术栈 Python / 模型 API / 环境交互与代码执行
- 环境：**MineDojo** 仿真开放世界。智能体从空背包出发自主行动，**最终目标：制作并获得铁镐（`iron_pickaxe`）**
- **科技树里程碑（11 项）**：原木 `log`/`log2` → 木板 `planks` → 木棍 `stick` → 工作台 `crafting_table` → 木镐 `wooden_pickaxe` → 圆石 `cobblestone` → 石镐 `stone_pickaxe` → 熔炉 `furnace` → 铁矿石 `iron_ore` → 铁锭 `iron_ingot` → 铁镐 `iron_pickaxe`
- **支线任务（额外分）**：获取煤炭/木炭、获取普通火把、放置普通火把
- 测评方式：多个**隐藏随机种子**世界，各局独立计分；**每局上限 3600 秒 / 5,000,000 Token（5M）**，触达任一即结束
- 资源额度：选手程序 **4 CPU / 2 GiB 内存**，独立环境 4 GiB，**无 GPU**；Token 按官方 API 平台计数
- **每局客观分（0～100，多局取算术平均）**：

  | 项目 | 分值 | 依据 |
  |---|---|---|
  | 科技树分 | 55 | 11 项里程碑完成情况（首次合法获得铁镐即满分） |
  | 支线任务分 | 5 | 煤炭/木炭、火把获取与放置 |
  | 效率分 | 40 | 木镐 / 石镐+熔炉 / 铁镐 三个检查点的达成步数 |
  | 死亡扣分 | 最多 −10 | 每次死亡 −2 |

- **提交材料**：**智能体代码 ZIP（必交）** + **技术报告 PDF（必交，中文 3000～5000 字）**；另有网页作品说明（**不能替代 PDF**）
- 运行方式：随作品上传 .zip，运行任务 `open-world`，**运行 3 次**
- **两个坑**：① **MineDojo 不支持 Windows** → 需 WSL2 + Ubuntu + Miniconda（开发包本身也不含启动脚本/Markdown 文档）；② 模型网关**不自动重试**，须自行捕获 `ModelResponseError`，重试耗时计入测评时限
- 参考工作：**Voyager**（生成行动代码、积累技能、按环境反馈改进）、**ReAct**（思考-行动-观察循环）、**MineDojo** 论文
- 学习路径（飞书《B 学习指导》）：入门视频 → 进阶课（实现 Agent 循环）→ 论文选读（ReAct → Voyager → MineDojo）
- 官方资料：题面页 / 开发包 / 计分规则 PDF / 技术报告模板见第六节，全文存档见 `官方资料存档/赛道B_无界探索_官方题面.md`

#### 赛道 B 计分规则明细（官方《智能体测评计分规则》PDF）

**里程碑分值（11 项，满分 55）** —— ★ 为标志里程碑，决定检查点步数：

| 阶段 | 里程碑（标识符） | 分值 |
|---|---|---|
| 木制 | 原木 `log/log2` | 2 |
| 木制 | 木板 `planks` | 2 |
| 木制 | 木棍 `stick` | 2 |
| 木制 | 工作台 `crafting_table` | 4 |
| 木制 | **木镐** ★ `wooden_pickaxe` | 5 |
| 石器 | 圆石 `cobblestone` | 4 |
| 石器 | **石镐** ★ `stone_pickaxe` | 6 |
| 石器 | **熔炉** ★ `furnace` | 5 |
| 铁器 | 铁矿石 `iron_ore` | 6 |
| 铁器 | 铁锭 `iron_ingot` | 7 |
| 铁器 | **铁镐** ★ `iron_pickaxe` | 12 |

- 科技树分：未获得铁镐时 = Σ 已达成分值；**首次合法获得铁镐即记满分 55**（未达成的算「补分项」）
- 支线任务分（满分 5）：煤炭/木炭 2 ｜ 获得火把 1 ｜ 放置火把 2（每项仅首次达成计分）
- 效率分（满分 40）：`Seff = 8·B木/(B木+C木) + 12·B石/(B石+C石) + 20·B铁/(B铁+C铁)`，参考步数 **B木=1500（木镐）｜ B石=6000（石镐与熔炉）｜ B铁=36000（铁镐）**；C 为检查点步数，未达成时该项取 0
- 死亡扣分：`D = min(2d, 10)`，d 为死亡次数；死亡后原地复活但**背包物品会掉落**（keepInventory 关闭）
- 单局得分：`S = clip(Stech + Sside + Seff − D, 0, 100)`；**最终成绩 = 各隐藏种子单局得分的算术平均，全程不舍入**
- 环境步计数：每次 `env.step` 计一步（含技能内部动作、空操作、无效动作、失败重试）；LLM 推理与 Token 不计步
- **作弊红线**：禁止除官方 LLM 端口外的任何联网（含联网查种子/矿物定位/云端 OCR）；禁止绕过 `env.step` 读写环境内部数据（背包/方块/种子/存档/内存/日志）；禁止重生世界、回滚状态、多进程并行试错；禁止人工代打或外部脚本代替 Agent 动作；禁止篡改记录
- **允许**：本地离线工具（本地 OCR、离线预计算、基于合法观测的推断）不算作弊；被测 Agent 内部可多模块/多角色，但对外视为一个 Agent

> 口径变化提醒：10-14 群文件的《无界探索_赛题说明.pdf》把三条工具链描述为「三个独立场景」；10-18 官网正式题面已改为「**单个开放世界**中的木制/石器/铁器三阶段 + 隐藏随机种子多局测评」。**一致以官网正式题面为准**。

### 赛道 C · 慧眼巧手（机械臂智能体操作）

- 关键词：Embodied Agent · 视觉理解 · 动作控制；技术栈 Python / LIBERO / 视觉模型与模型 API
- 环境：**LIBERO** 仿真桌面操作，按自然语言任务 + 相机画面 + 机械臂状态完成三个任务：
  1. 从桌面中央抓取**黑碗**，放到**盘子**上
  2. 将**字母汤罐**放入**篮子**
  3. 将**字母汤罐和番茄酱**两件物品放入**篮子**
- 资源：可联系 AI 社申请 **API 支持**；提供练习任务、开发示例与统一测评
- 测评指标：三个任务的完成情况（由 LIBERO 仿真环境判定抓取与摆放目标是否达成）
- 交付：控制策略或智能体代码、运行配置、技术报告与运行说明（可附操作视频）
- 参考：LIBERO 的仿真任务、控制接口、示范数据与模仿学习
