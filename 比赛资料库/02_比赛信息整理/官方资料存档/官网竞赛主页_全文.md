三条赛道独立评测、评审和排名。各题页面提供任务边界、输入输出协议、公开开发包、提交要求与计分公式。

## 如何参赛

1. 注册账号，在工作台创建或加入队伍，为队伍报名对应赛道。
2. 阅读题面与资源面板，下载开发包；完成代码、训练或策略开发与练习验证。
3. 按题目要求准备程序 ZIP、模型或运行配置。
4. 在题目提交页正式提交材料，补齐技术路线说明、README 和复现说明。
5. 接受统一材料评审、成果复现与现场答辩，公布成绩并展示优秀作品。

模型接口与训练算力按题目统一额度提供，队伍训练实例与组织方测评环境相互独立。

## 评分与诚信

最终成绩 = 模型或智能体实际表现 × 50% ＋ 技术路线说明 × 10% ＋ 现场答辩 × 40%。实际表现分严格按题面公式计算。技术路线说明考察设计、实现、结果分析、复现与引用，研究和对照实验可选。答辩包含方案介绍、运行演示和现场问答。

允许引用论文、开源代码和工具，须声明来源、改动和团队分工。抄袭、共享隐藏测试信息、使用泄露标签、伪造指标或作弊，取消获奖资格。

## 赛程与资源

报名、开赛、提交截止与答辩时间由组织方在本赛事页面统一公布，奖项明细另行公告。人体行为识别数据已固定并内置于训练、测评两版镜像；两条智能体赛道的模型渠道待配置。具体资源安排以赛事页面和资源面板为准。

组织方将在正式开放前发布数据获取与使用授权、类别映射、训练验证划分、模型名称、训练 GPU 类型和每队额度。题面和开发协议可先用于准备，样例或原赛事成绩不能替代本届正式测评。

## 通用参赛流程

创建队伍 → 报名赛道 → 阅读题目 → 提交 README 与作品材料 → 按版本评审。本场规则：每队 1–3 人，每队最多报名 1 条赛道，同一账号只能在一支队伍里。
