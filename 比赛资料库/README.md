## 速览

- **官网**：<https://uestcai.top/competitions/wujie-cup-2026>
- **赛道 B 题面**：<https://uestcai.top/competitions/wujie-cup-2026/tracks/world-exploration/problems/wujie-open-world-agent>（正式赛题 **WJ-OW-001**）
- **组队**：1–3 人，每队限报 1 条赛道，同一账号只能在一支队伍里
- **时间**：报名/开赛 **10-18**，比赛结束（第一阶段测评）**11-20**，现场答辩 **11-30**（暂定）
- **计分**：模型/智能体实际表现 **50%** ＋ 技术路线说明 **10%** ＋ 现场答辩 **40%**

- **注意**：MineDojo **不支持 Windows** → 需 WSL2 + Ubuntu + Miniconda；每局限时 3600 秒 / 5M Token；选手程序 4CPU / 2GiB，无 GPU
